# 🌐 Personal Portfolio

A personal portfolio website showcasing my **skills, education, projects, and journey as a Web Developer.**

### ✨ Features

- Responsive and modern UI
- About Me & Education
- Skills & Projects
- Dark and Light Mode
- Contact Section
- Smooth Navigation

### 🛠️ Built With

- HTML5
- CSS3
- JavaScript

### 🚀 Getting Started

```bash
git clone https://github.com/susmita-del/Portfolio.git
```

Open the project folder and run `index.html` in your browser, or use VS Code Live Server.
